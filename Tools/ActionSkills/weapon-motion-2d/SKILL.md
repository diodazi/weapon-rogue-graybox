# 2D 兵器动作指导

将武器的结构、参考动作的运动逻辑和游戏可读性结合，交付可画、可演示、可实现的动作规格。使用用户的语言沟通。

## 先确定动作主体

读取现有设计文档、相关动作配置和本轮参考；有 `Docs/GDD_MVP.md` 时先检查其中的角色、视角、美术及动作规则。最新用户要求优先，旧岗位文档或技能示例不能覆盖现行设计。

- **人持武器**：记录支撑脚、重心、躯干与手的关系，再描述握点和武器轨迹。
- **武器本体**：人体只作为理解参考的辅助。把步法转成武器根节点位移，把握持控制转成虚拟支点，把躯干蓄势转成武器朝向与位移的预备变化；不要凭空增加人、手、骨架或脚步动画。
- **视角**：明确横板、俯视或斜视。没有说明且现有资料无法确定时，做带标记的暂定选择；方向翻转、镜头移动和美术假透视分别记录。

## 设计流程

1. **动作目的**：说明玩家需要辨认什么，如直线突进、上方覆盖、反向回切或移动刹停。沿用已批准规则；不要因动作漂亮就添加伤害、追踪、无敌或取消能力。
2. **武器画像**：长度和比例、刃尖/刃缘/柄端、实际或虚拟握点、质量分布假设、可动与刚性部件。名称不能代替具体造型。按需读 [兵器研究方法](references/weapon-families.md)。
3. **参考证据**：有视频、图片或动捕时先核对真实可见内容；采用来源、时间点、观察、推断、改编分开的记录。没有实际看过视频时，不写逐帧观察或招式鉴定。可用 `motion-reference-analysis` 辅助，但本流程不依赖该技能安装。
4. **关键姿势**：按动作需要选择起势、预备极值、释放、有效接触、随动、制动、结束。不是每招都需固定七张图；接触是时间事件，可与姿势重合。记录尖、根、有效刃的路径和起止朝向。
5. **2D 转译**：保留攻击意图、运动先后和接触方向；处理深度消失，说明哪些是真实投影，哪些是为了可读性重新编排。遵循下方平面化约束。
6. **节奏**：用毫秒或秒作为可比较时长；若给帧数，注明时间基准。区分动画绘制曝光、视频采样和游戏模拟时钟。先定关键时刻和路径，再调帧间距离，避免整段等速摆动或机械往返。
7. **衔接**：上一招终态必须能成为下一招起态。检查位置、方向、剩余运动趋势、支点和制动；明显换面或反转要有可读过渡。取消、打断、落地、换向和恢复仍服从游戏已有规则。
8. **交接**：按 [动作规格](references/motion-spec.md) 输出适量的关键姿势表、路径/节奏说明、事件时间线、素材需求和检查项。对未知数值明确标记为建议或原型值，不伪装成实测。

## 平面化约束

- 明确坐标：示意图可采用屏幕右为 +X、上为 +Y，朝右为 0°，逆时针为正；引擎或 Canvas 使用另一套坐标时显式转换。根节点、虚拟支点、武器局部原点不是同一概念。
- 单目视频无法唯一恢复 3D 深度。区分“参考在画面中的轨迹”与“推断的空间路径”。不要把沿镜头刺出的短投影误作动作幅度小。
- 侧视刺击需要保留沿武器长轴的伸出与回收，斩击需要保留可读的刃缘扫掠；不要把每种攻击都重做成绕中心旋转。
- 深度动作可以通过姿势重排、局部角度偏移、前后层级、换面图或适度缩短表达；这些是视觉改编，不自动改变逻辑距离、受击区或接触判定。
- 保留刚性武器的长度关系；高速拉伸帧、纸片形变及拖影单独说明。不能因传统动画强调挤压拉伸，就将钢制刃身或所有纸片持续做成果冻。
- 静态旋转支点会影响整条尖端路径；移动支点必须保持连续，并说明是视觉控制还是逻辑根节点位移。不要用暗中伸长武器掩盖错误支点。
- 镜像检查尖端、刃向、非对称造型与目标方向；禁止镜像后同一招出现反刃击打或判定漂移而未被发现。

## 游戏与动画的接口

区分视觉轮廓、有效攻击区域、受击区域和纯特效。拖影留下不等于攻击仍生效，武器外形碰到也不必然代表规则允许结算。

设计中对齐输入响应、位移、预警、生效、接触、受击反应、恢复及允许衔接。命中、挥空和被格挡可有不同表现，但是否存在这些分支由项目规则决定。多人镜头下不要默认全局停时；停顿作用对象、时钟、叠加与恢复需要既有系统支持。

受控物理项目中，姿势曲线是目标或表现说明，不是直接逐帧覆盖物理位置的许可。动画、控制器和物理不能各自同时驱动同一根节点；由现有实现确定驱动权和数据入口。

## 验收与输出边界

- 实际游戏尺寸下，关闭拖影、震屏和音效后，仍能读出起手方向、动作性质与结束状态。
- 普速用于判断可读性，慢放用于定位轨迹和衔接问题；两种检查不能互相替代。
- 检查左右朝向、落地/空中、起止连接；适用时再测命中、挥空、格挡、中断和多人遮挡。
- 每种武器的差异落实在路径、节奏、支点与回收，不只换颜色、尺寸或招式名字。
- 只有真实运行或播放过的内容才能标为“已验证”。文档审阅、结构校验与实机动作验收分开报告。
- 参考研究会形成可复用的项目笔记与动作规格，不宣称安装技能等于获得新的模型训练或已掌握所有武术流派。
